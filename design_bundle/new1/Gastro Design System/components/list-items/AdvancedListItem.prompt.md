# AdvancedListItem

Full-featured list row — leading icon/avatar, title, subtitle, trailing node/chevron. Heights 56 (one-line) / 72 (two-line). For a bare label + arrow, use `SimpleListItem`.

```jsx
<AdvancedListItem leadingIcon="map-pin" title="Home" subtitle="12 Almond St, Apt 4" chevron onClick={edit} />
```
