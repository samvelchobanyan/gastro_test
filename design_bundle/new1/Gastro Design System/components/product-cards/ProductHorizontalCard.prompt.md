# ProductHorizontalCard

Horizontal product row: small square photo left, product name (Body Small) and price (Body Extra Small) stacked right. Same content as ProductVerticalCard with the image at half size (64px).

```jsx
<ProductHorizontalCard name="Margherita Pizza" price="2,400 ֏" imageUrl={img} />
```

Full-width row; image is a swappable placeholder.
