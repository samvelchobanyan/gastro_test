# RestaurantHeader

Full-width hero header for a restaurant's own screen — cover photo with name, description and rating overlaid, kept readable by a bottom-up gradient scrim. Cover defaults to a restaurant photo if none is given.

```jsx
<RestaurantHeader coverImage={img} name="Nolana Pizzeria"
  description="Wood-fired Neapolitan pizza, made fresh daily"
  rating={4.6} reviewCount={128} isOpen onBack={back} />
```
