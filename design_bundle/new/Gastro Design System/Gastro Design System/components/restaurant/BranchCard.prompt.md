# BranchCard

Row for one physical location in a branch picker/listing — photo, name, address, working hours, open/closed status.

```jsx
<BranchCard image={img} name="Nolana Pizzeria — Downtown" address="12 Almond St, Suite 4"
  hours="Mon–Sun · 11:00–22:00" isOpenNow distance="1.2 km" onClick={selectBranch} />
```
