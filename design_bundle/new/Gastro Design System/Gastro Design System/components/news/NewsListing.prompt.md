# NewsListing

Image + title + publish date item for restaurant news, announcements or blog posts. Horizontal layout — thumbnail beside text, for list feeds.

```jsx
<NewsListing image="/news/promo.jpg"
  title="Weekend brunch menu is back" publishedAt="Jul 2, 2026" onClick={...} />
```

Pass `onClick` to make it an interactive button; title clamps to 2 lines.
