# StatusPill

Small text status pill (Open/Closed, Active/Inactive, Available/Sold out). Soft tonal background + matching text color, Body Small on a full-radius capsule.

```jsx
<StatusPill tone="success">Open</StatusPill>
<StatusPill tone="error">Closed</StatusPill>
```

Tones: `success`, `error`, `warning`, `neutral`. Used inside `BranchCard` for the open/closed state.
