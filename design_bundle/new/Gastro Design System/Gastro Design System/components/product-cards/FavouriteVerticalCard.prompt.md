# FavouriteVerticalCard

Vertical product card mirroring BuyAgainCard, but the second line is a **price** (Body Extra Small) instead of a location. Photo, name (Body Small), price.

```jsx
<FavouriteVerticalCard name="Margherita Pizza" price="2,400 ֏" imageUrl={img} />
```

Same 128px width and image size as BuyAgainCard; image is a swappable placeholder.
