## Компоненты — обязательно

**6. `BottomNavigation.json` — высота числом, и число не совпадает с токеном.**
Высота корня — число `64`, вариант `showLabels: false` ставит `56`, в `notes` написано
«(64px)». При этом токены `--bottomnav-height` и `--bottomnav-height-labeled` равны
`48px`. Убрать числа, оставить только ссылку на токен.

**7. `LoyaltyPointsCard.json` — дерево и проза противоречат.**
У колонки `left` записано `spacing: [0, 0]`, а в `notes` сказано, что над плашкой уровня
есть отступ `--space-xs`. Положить `--space-xs` в `spacing`.

**8. `TabBar.json` — активный вид маленького таба только в прозе.**
Как выглядит активный маленький таб (фон `--gray-0`, рамка `--color-brand-primary`, текст
`--color-text-accent`), написано только в `notes`. В `variants` случай `active` меняет лишь
цвет текста на `--color-text-primary` — это вид большого таба. Добавить в `variants`
случай `small × active`.

**9. `Button` — при экспорте проверить фон и радиус по умолчанию.**
В выгрузке `Button` нет (п. 1), но в копии из UI-проекта у него нет ни `background`, ни
`radius` для вида по умолчанию (primary, md): `surface: null`, фон появляется только в
вариантах `secondary` / `tertiary` / `destructive`. Нужен `surface: { background:
"--button-primary-bg", radius: … }`. Кроме того, `Wallet.json` вызывает `Button` с
`"radius": "full"` (капсула), а у `Button` оси `radius` нет. Добавить ось.

**10. `MembershipTierPill` — при экспорте указать заливку.**
В выгрузке нет (п. 1). В копии из UI-проекта в `description` сказано «полупрозрачная плашка
на тёмных поверхностях», а в дереве фона нет совсем. Указать заливку (`--alpha-white-8` /
`-12` / `-24` — какая по дизайну). `padding` там же записан числами `12` / `4`, хотя есть
токены `--space-md` / `--space-xs`.

## Компоненты — желательно: факт есть, но только в `notes`

**11. `Stories.json` — белый зазор только в прозе.**
Между цветным кольцом и фото есть зазор 2px цвета `--color-bg-surface`. Об этом сказано
только в `notes`. Записать как `border` на узле `photo`.

**12. `Dropdown.json` — раскрытое меню только в прозе.**
Как выглядит открытый список (подложка, радиус, тень, строки, выбранная строка) — только в
`notes`. Добавить узел `menu`, скрытый по умолчанию и показываемый вариантом `open`.

**13. Вес шрифта в `notes` у восьми файлов.**
`BuyAgainCard`, `ProductVerticalCard`, `ProductMenuCard`, `SectionHeader`, `Greeting`,
`ScreenHeader`, `Wallet`, `Badge` пишут в `notes` «вес bold/semibold поверх `--text-…`».
Либо токен уже несёт этот вес (`--text-h1`, `--text-h3` в `typography-scale.json` уже bold —
тогда заметка лишняя), либо нужного токена нет (`--text-body-sm-semibold` — см. п. 2).
Добавить недостающие `--text-*` в токены, ссылаться на них в `style`, заметки убрать.

## Компоненты — косметика

**14. `"transparent"` как значение фона.**
В `Greeting`, `IconButton`, `ScreenHeader`, `TabBar`, `Wallet` поле `background` содержит
слово `"transparent"`. По формату значение — токен, число или слово из закрытого списка;
`"transparent"` — слово из CSS. «Без заливки» записывается как `null`.

**15. Длина `spacing` не равна `детей − 1`.**
Нарушено в `BranchCard` (корень и строка часов), `Dropdown`, `Greeting`,
`MenuTabsVertical`, `ProductMenuCard`, `ScreenHeader`, `TabBar`, `Wallet`. Ноль записан
двумя способами: `[0, 0]` и `[]`. Выбрать один.

**16. `padding` строкой вместо объекта.**
В `MenuTabsVertical`, `ProductMenuCard`, `TabBar` написано `"padding": "--space-xs"`;
по формату это объект `{ "all": "--space-xs" }` или по сторонам.

**17. Поля, которых нет в формате.**
`overlayImage` (`LoyaltyPointsCard`), `weight` на текстовом узле (`MenuTabsVertical`,
`TabBar`), `rotate` (`Dropdown`), `margin` (`Divider`), `opacity` (`Dropdown`, `IconButton`),
`scale` (`BranchCard`); вычисляемые размеры `{1/n}`, `{size+8}`, `{width}`. Каждое —
реальная потребность, поэтому мы добавим их в `FORMAT.md`, а не будем просить убрать.
Пока — считать расширениями.

**18. `shows.children` в `BranchCard`, `Wallet`.**
`children` — имя пропса из React. Использовать имя слота с содержимым (`label`).

**19. `Badge.json` — имя со скобками.**
`name` записан как `"Badge (count)"`. Имя — идентификатор, скобок быть не должно.
